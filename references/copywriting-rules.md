# Copywriting Rules

A slide's text is part of its design. These rules apply to every title, bullet,
and caption, for both `brand-rebuild` (rewriting needs permission, but
recomposed headings follow these) and the future `topic-to-deck` mode.

## Titles State the Conclusion

A title is a claim, not a label. If the audience only reads titles, they should
still get the whole argument.

| Label (bad) | Conclusion (good) |
| --- | --- |
| 关键数据 | 用量 6 个月翻倍 |
| 我们的方案 | 一个平台替代五个工具 |
| 市场分析 | 下沉市场是下一轮增长点 |
| 服务保障团队 | 7×24 专属团队实时处置故障 |

## One Core Message

Before authoring, write the deck's one core message in ≤15 characters, then 3–5
supporting points ordered by audience relevance, not by source order. Every
slide serves one of those points.

## Audience First

| Audience | Emphasis | Visual treatment |
| --- | --- | --- |
| 高管 | 结论、ROI、战略影响 | 高度概括、突出数据 |
| 技术 | 架构、实现、规格 | 图示、流程、对比 |
| 大众 | 收益、故事、共鸣 | 隐喻、简单图表 |
| 投资人 | 市场、增长、团队 | 增长曲线、里程碑 |
| 学习者 | 步骤、示例 | 编号步骤、渐进展开 |

## No Filler

- Ban AI clichés: 「让我们一起探索」「深入了解」「激动人心」「总而言之」「赋能」.
  Write directly and with confidence.
- No placeholders: never leave 「[待补充]」「TBD」「请输入文字」.
- No page furniture that the source or outline did not establish.

## Data Carries a Source

Every number, claim, or statistic has a source: a small caption on the page
(「来源：…」) or a `[Sources]` block in the speaker notes.

## Closing Has a Point

The final slide is a memory point, a call to action, or a next step — never
「谢谢观看」.

## Chinese Copy

- Use full-width punctuation and corner quotes (「」/“”); see `cjk-typography.md`.
- Insert a narrow space between CJK and Latin/digits: `增长 42%`，not `增长42%`.
- Keep technical terms and brand names in their original form (5G 消息、A 股、
  Webhook), but translate filler into clear Chinese.
- Prefer short clauses; a Chinese sentence over ~40 characters reads dense — split it.
